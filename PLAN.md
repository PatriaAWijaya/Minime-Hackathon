# Build plan — Minime-Hackathon

Scope rule (from the hackathon's "new work only" rule for the Indie track):
only work in this repo, built 27 Oct – 4 Nov 2026, is presented. Nothing is
copied from the main Minime repository.

## Phases

- **Phase 0 — Scaffold (done 27 Oct 2026):** repo, README, plan, license.
- **Phase 1 — Orchestrator core:** brief in, task split across a small agent
  roster, validated structured artifacts between agents.
- **Phase 2 — Meta-native layer + eval harness:** Muse via the Meta Model API
  as the default brain; live metrics: routing quality, task success,
  latency, cost per completed task.
- **Phase 3 — Human approval gate + UI:** nothing consequential without
  explicit approval; a thin dashboard showing agent status and outputs.
- **Phase 4 — Demo + submission:** 3-minute demo video showing ONLY the work
  in this repo, then the submission form before 4 Nov 2026, 9:00 PM ET.

## Stack (to be confirmed at build start)

Tauri 2 + Svelte 5 (same family as Minime, written fresh here) or a web-only
demo if the remaining window demands it. Decision recorded here when made.
